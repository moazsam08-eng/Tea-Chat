---
name: Tea Chat brand direction
description: The user's standing visual and usability direction for Tea Chat.
---

Keep the product named Tea Chat and use a tea-inspired visual language throughout the app. The user wants the experience to feel smooth, simple, and easy to use, including on mobile.

**Why:** The user explicitly requested a full tea-themed redesign and emphasized smooth, easy-to-use interactions; this product direction is not fully derivable from the code.

**How to apply:** Use this direction for future Tea Chat screens and interaction states unless the user changes it.
